# 是 (shì)

:::note
In Mandarin, **是 (shì)** functions as an equational verb linking a **Noun to another Noun** (*A = B*).  
It does **not** link nouns directly to adjectives (use **很 hěn**) or locations (use **在 zài**).
:::

Use **是** to state identity, nationality, profession, or categorical classification:

> **Formula:** Subject (Noun / Pronoun) + **是 (shì)** + Noun Phrase

---

## 1. Core Sentence Patterns

| Form | Pattern | Example Sentence |
| :--- | :--- | :--- |
| **Affirmative** | Subj + **是** + Noun | [我是中国人。 Wǒ shì Zhōngguórén.](wo3shi4zhong1guo2ren2.wav) <br /><small>⤷ I am Chinese.</small> |
| **Negative** | Subj + **不是** + Noun | [他不是医生。 Tā bú shì yīshēng.](ta1bu2shi4yi1sheng1.wav) <br /><small>⤷ He is not a doctor.</small> |
| **Question (吗)** | Subj + **是** + Noun + **吗**？ | [你是学生吗？ Nǐ shì xuésheng ma?](ni3shi4xue2sheng0ma0.wav) <br /><small>⤷ Are you a student?</small> |
| **Question (A-not-A)** | Subj + **是不是** + Noun？ | [他是不是你哥哥？ Tā shì bu shì nǐ gēge?](ta1shi4bu0shi4ni3ge1ge0.wav) <br /><small>⤷ Is he your older brother?</small> |

---

## 2. When CAN 是 Be Used with Adjectives?

While you cannot say *我是高兴* (*I am happy*), there are two specific structures where **是** pairs with adjectives:

### A. The 是……的 Pattern (Category & Inherent Properties)
When an adjective describes a permanent quality, category, color, or material, attach **的 (de)** to nominalize the adjective:

> **Formula:** Subject + **是** + Adjective + **的**

* [这个苹果是红的。 Zhè ge píngguǒ shì hóng de.](zhe4ge0ping2guo3shi4hong2de0.wav)  
  <br /><small>⤷ This apple is a red one.</small>
* [这辆车是新的。 Zhè liàng chē shì xīn de.](zhe4liang4che1shi4xin1de0.wav)  
  <br /><small>⤷ This car is a new one.</small>
* [这把雨伞是黑色的。 Zhè bǎ yǔsǎn shì hēisè de.](zhe4ba3yu3san3shi4hei1se4de0.wav)  
  <br /><small>⤷ This umbrella is black.</small>

---

### B. Emphatic Confirmation ("It *IS* true that...")
When you want to emphatically confirm a statement or counter someone's doubt, stress the word **是**:

* A: *今天不冷吧？ (It's not cold today, right?)*  
  B: [今天天气是冷！ Jīntiān tiānqì shì lěng!](jin1tian1tian1qi4shi4leng3.wav)  
  <br /><small>⤷ Today's weather **is** indeed cold!</small>

---

## 3. The 是……的 (shì... de) Construction: Emphasizing Past Details

When an event has already occurred, **是** pairs with **的** to highlight a specific known detail: **when, where, how, or by whom** the action took place.

> **Formula:** Subject + **是 (shì)** + **[Emphasized Detail]** + Verb + **的 (de)**

| Emphasized Detail | Focus | Example Sentence |
| :--- | :--- | :--- |
| **Time** | *When* it happened | [我是昨天来的。 Wǒ shì zuótiān lái de.](wo3shi4zuo2tian1lai2de0.wav) <br /><small>⤷ I arrived **yesterday**.</small> |
| **Place** | *Where* it happened | [我们是在上海认识的。 Wǒmen shì zài Shànghǎi rènshi de.](wo3men0shi4zai4shang4hai3ren4shi0de0.wav) <br /><small>⤷ It was **in Shanghai** that we met.</small> |
| **Manner / Means** | *How* it was done | [他是坐火车去的。 Tā shì zuò huǒchē qù de.](ta1shi4zuo4huo3che1qu4de0.wav) <br /><small>⤷ He went **by train**.</small> |
| **Agent** | *Who* performed it | [这本书是他写的。 Zhè běn shū shì tā xiě de.](zhe4ben3shu1shi4ta1xie3de0.wav) <br /><small>⤷ This book was written **by him**.</small> |

---

## 4. Concessive 是: "It *is* X, but..." (是……但是……)

To acknowledge a point or drawback before presenting a contrasting reality, repeat the adjective or verb around **是**:

> **Formula:** [Adjective / Verb] + **是** + [Adjective / Verb]，**但是…… (dànshì...)**

* [贵是贵，但是很好用。 Guì shì guì, dànshì hěn hǎoyòng.](gui4shi4gui4dan4shi4hen3hao3yong4.wav)  
  <br /><small>⤷ It **is** expensive, but it works really well.</small>
* [去是去，但是我不想待太久。 Qù shì qù, dànshì wǒ bù xiǎng dāi tài jiǔ.](qu4shi4qu4dan4shi4wo3bu4xiang3dai1tai4jiu3.wav)  
  <br /><small>⤷ I **will** go, but I don't want to stay too long.</small>

---

## 5. Answering "Yes" / "No" with 是

Mandarin has no universal word for "yes". However, when a question confirms identity or asks with **是**, respond using:

| Response | Usage / Tone | Example |
| :--- | :--- | :--- |
| **是** | Direct affirmation | [是。 Shì.](shi4.wav) <br /><small>⤷ Yes / That is correct.</small> |
| **是的** | Polite / conversational confirmation | [是的。 Shìde.](shi4de0.wav) <br /><small>⤷ Yes, that's right.</small> |
| **不是** | Direct denial | [不是。 Bú shì.](bu2shi4.wav) <br /><small>⤷ No / That's not correct.</small> |
