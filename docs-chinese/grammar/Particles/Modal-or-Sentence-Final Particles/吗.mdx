# 吗 (ma)

The character **吗** is predominantly pronounced in the neutral tone: **`ma`**. 

It is the foundational **yes/no question particle** in Mandarin Chinese. Unlike English, which requires changing word order or adding auxiliary verbs ("Do you...", "Are you..."), Chinese simply appends **吗** to the end of a declarative sentence.

| Usage Type | Grammatical Function | English Equivalent | Quick Anchor |
| :--- | :--- | :--- | :--- |
| **1. Yes/No Questions** | Converts a statement into a binary question | "...?" / "Is it true that...?" | [你好吗？; Nǐ hǎo ma?; How are you?](ni3hao3ma0.wav) |
| **2. Rhetorical Questions** | Emphasizes an obvious fact or reminder | "Isn't it...?" / "Don't you...?" | [这不是很好吗？; Zhè bú shì hěn hǎo ma?; Isn't this great?](zhe4bu2shi4hen3hao3ma0.wav) |
| **3. Tag Confirmation** | Asks for consent or agreement | "Okay?" / "Can we?" | [可以吗？; Kěyǐ ma?; Is that okay?](ke3yi3ma0.wav) |
| **4. Phonetic Loanword (`mǎ`)** | Transliteration character (3rd tone) | Chemical/medical loanwords | [吗啡; mǎfēi; morphine](ma3fei1.wav) |

## 1. Standard Yes/No Questions

To turn any declarative statement into a yes/no question, keep the exact same word order and add **吗** at the very end.

> **Pattern:** `Declarative Statement + 吗？`

| Base Statement (Hanzi & Pinyin) | Question with 吗 | English Meaning |
| :--- | :--- | :--- |
| 你是学生。<br />(*Nǐ shì xuésheng.*) | [你是学生吗？; Nǐ shì xuésheng ma?; Are you a student?](ni3shi4xue2sheng0ma0.wav) | Confirms identity |
| 他去过中国。<br />(*Tā qù guò Zhōngguó.*) | [他去过中国吗？; Tā qù guò Zhōngguó ma?; Has he been to China?](ta1qu4guo4zhong1guo2ma0.wav) | Confirms past experience |
| 你喜欢喝茶。<br />(*Nǐ xǐhuan hē chá.*) | [你喜欢喝茶吗？; Nǐ xǐhuan hē chá ma?; Do you like drinking tea?](ni3xi3huan0he1cha2ma0.wav) | Confirms preference |
| 你准备好了。<br />(*Nǐ zhǔnbèi hǎo le.*) | [你准备好了吗？; Nǐ zhǔnbèi hǎo le ma?; Are you ready?](ni3zhun3bei4hao3le0ma0.wav) | Confirms state completion |

## 2. Rhetorical Questions & Reminders

When combined with negative adverbs like **不是** (*bú shì*) or rhetorical markers like **难道** (*nándào*), **吗** forms questions where the speaker already expects agreement.

> **Pattern A:** `Subject + 不是 + Predicate + 吗？` ("Isn't it true that...?")  
> **Pattern B:** `难道 + Statement + 吗？` ("Could it really be that...?")

| Rhetorical Formula | Example Sentence | Implied Meaning |
| :--- | :--- | :--- |
| **不是……吗？** | [今天不是星期天吗？; Jīntiān bú shì Xīngqītiān ma?; Isn't today Sunday?](jin1tian1bu2shi4xing1qi1tian1ma0.wav) | "Today is definitely Sunday; why are you acting otherwise?" |
| **不是……吗？** | [这不是很明显吗？; Zhè bú shì hěn míngxiǎn ma?; Isn't this obvious?](zhe4bu2shi4hen3ming2xian3ma0.wav) | "This is completely obvious." |
| **不是……吗？** | [他不是你的朋友吗？; Tā bú shì nǐ de péngyou ma?; Isn't he your friend?](ta1bu2shi4ni3de0peng2you0ma0.wav) | "I thought he was your friend." |
| **难道……吗？** | [难道你不知道吗？; Nándào nǐ bù zhīdào ma?; Could it be that you don't know?](nan2dao4ni3bu4zhi1dao4ma0.wav) | "You should definitely know this." |

## 4. Special Pronunciations: `mǎ` & `má`

While **吗** is overwhelmingly a neutral tone particle, it has two specific exceptions:

| Word | Pinyin | Meaning | Note |
| :--- | :--- | :--- | :--- |
| [吗啡; mǎfēi; morphine](ma3fei1.wav) | `mǎ` (3rd tone) | Morphine (analgesic drug) | Standard transliteration loanword |
| [干吗; gànmá; why / what for](gan4ma2.wav) | `má` (2nd tone) | Spoken colloquial for "Why are you doing that?" | Often interchangeably written as 干嘛 |

## 5. Critical Pitfalls: When NOT to Use 吗

A universal rule in Mandarin grammar is that **two question methods cannot be combined in one sentence**. If a question structure already exists, **never** add **吗**.

| Conflict Type | Incorrect Structure | Correct Natural Version | Explanation |
| :--- | :--- | :--- | :--- |
| **Question Words**<br />(*什么 / 谁 / 哪儿*) | 他是谁吗？❌ | [他是谁？; Tā shì shéi?; Who is he?](ta1shi4shei2.wav) | Question pronouns already mark the question. |
| **Question Words**<br />(*什么 / 怎么*) | 你在看什么吗？❌ | [你在看什么？; Nǐ zài kàn shénme?; What are you looking at?](ni3zai4kan4shen2me0.wav) | Adding 吗 here is ungrammatical. |
| **A-not-A Form**<br />(*V-不-V*) | 你想不想去吗？❌ | [你想不想去？; Nǐ xiǎng bu xiǎng qù?; Do you want to go or not?](ni3xiang3bu0xiang3qu4.wav)<br />*— or —*<br />[你想去吗？; Nǐ xiǎng qù ma?; Do you want to go?](ni3xiang3qu4ma0.wav) | Choose **either** the A-not-A form **or** 吗, never both. |
| **Alternative Choice**<br />(*还是*) | 你喝茶还是咖啡吗？❌ | [你喝茶还是喝咖啡？; Nǐ hē chá háishi hē kāfēi?; Do you drink tea or coffee?](ni3he1cha2hai2shi4he1ka1fei1.wav) | **还是** (*or*) already sets up an alternative question. |
