# 之 (zhī)

## Spatial & Temporal Boundary Markers

In standard modern Chinese, **之** regularly combines with positional words to create fixed time and space boundaries.

> **Pattern:** `Time / Event / Location + 之 + Directional Word`

| Boundary Marker | Meaning | Context Example |
| :--- | :--- | :--- |
| [之前; zhīqián; before / prior to](zhi1qian2.wav) | Prior to a point in time | [睡觉之前不要吃东西。; Shuìjiào zhīqián bú yào chī dōngxi.; Don't eat before going to sleep.](shui4jiao4zhi1qian2bu2yao4chi1dong1xi0.wav) |
| [之后; zhīhòu; after / afterwards](zhi1hou4.wav) | Subsequent point in time | [下课之后我给你打电话。; Xiàkè zhīhòu wǒ gěi nǐ dǎ diànhuà.; I will call you after class.](xia4ke4zhi1hou4wo3gei3ni3da3dian4hua4.wav) |
| [之间; zhījiān; between / among](zhi1jian1.wav) | Spatial interval or relationship | [朋友之间要互相帮助。; Péngyou zhījiān yào hùxiāng bāngzhù.; Friends should help one another.](peng2you0zhi1jian1yao4hu4xiang1bang1zhu4.wav) |

## Formal & Written Equivalent of 的 (de)

In formal literature, news reports, and idiomatic expressions, **之** connects a descriptive modifier to a noun, functioning just like **的** but in a much more elevated register.

> **Pattern:** `Modifier / Attribute + 之 + Head Noun`
