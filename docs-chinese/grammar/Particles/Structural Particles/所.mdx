# 所 (suǒ)

The character **所** is pronounced in the 3rd tone: **`suǒ`**. 

It is one of the most flexible structural components in Mandarin Chinese, functioning as a **nominalizing particle**, a **passive marker**, a **measure word**, and a **noun root** for physical locations and institutions.

| Grammar Function | Role | English Equivalent | Quick Anchor |
| :--- | :--- | :--- | :--- |
| **1. Structural Particle** | Nominalizes actions (`所 + Verb`) | "that which" / "what is [verbed]" | [所需要的; suǒ xūyào de; that which is needed](suo3xu1yao4de0.wav) |
| **2. Formal Passive Voice** | Emphasizes the receiver in passive sentences | "is [verbed] by..." | [为人所知; wéi rén suǒ zhī; known by people](wei2ren2suo3zhi1.wav) |
| **3. Measure Word** | Classifier for institutions, schools, hospitals | "a / an" (institution) | [一所学校; yì suǒ xuéxiào; a school](yi4suo3xue2xiao4.wav) |
| **4. Location Noun Root** | Base morpheme meaning "place" or "facility" | place / office / station | [厕所; cèsuǒ; restroom](ce4suo3.wav) |
| **5. Core Conjunctions** | Forms foundational connectors | therefore / all / so-called | [所以; suǒyǐ; therefore / so](suo3yi3.wav) |

## 1. Structural Particle: `所 + Verb (+ 的)`

When placed directly in front of a transitive verb, **所** turns the verb phrase into the **object of the action**, meaning "that which is [verbed]" or "what is [verbed]."

> **Pattern:** `Subject + 所 + Verb + (的 + Noun)`

| :--- | :--- | :--- |
| [所需要的; suǒ xūyào de; that which is needed / what is needed](suo3xu1yao4de0.wav) | Things required | [这正是我们所需要的。; Zhè zhèng shì wǒmen suǒ xūyào de.; This is precisely what we need.](zhe4zheng4shi4wo3men0suo3xu1yao4de0.wav) |
| [所说的; suǒ shuō de; what was said / that which was spoken](suo3shuo1de0.wav) | Statements made | [你所说的事情属实吗？; Nǐ suǒ shuō de shìqing shǔshí ma?; Is what you said true?](ni3suo3shuo1de0shi4qing0shu3shi2ma0.wav) |
| [所见所闻; suǒ jiàn suǒ wén; what one sees and hears](suo3jian4suo3wen2.wav) | First-hand experience | [这些都是我的所见所闻。; Zhèxiē dōu shì wǒ de suǒ jiàn suǒ wén.; These are all things I personally saw and heard.](zhe4xie1dou1shi4wo3de0suo3jian4suo3wen2.wav) |

## 2. Formal Passive Construction: `为 / 被……所 + Verb`

In formal, literary, and journalistic Chinese, **所** is inserted before the verb in passive sentences to emphasize the action's recipient.

> **Pattern A:** `Receiver + 被 + Agent + 所 + Verb`  
> **Pattern B (Literary):** `Receiver + 为 + Agent + 所 + Verb`

| Passive Pattern | Meaning | Complete Sentence |
| :--- | :--- | :--- |
| [为大家所熟悉; wéi dàjiā suǒ shúxī; well known by everyone](wei2da4jia1suo3shu2xi1.wav) | Widely recognized | [这个故事为大家所熟悉。; Zhè ge gùshì wéi dàjiā suǒ shúxī.; This story is well known to everyone.](zhe4ge0gu4shi4wei2da4jia1suo3shu2xi1.wav) |
| [被大家所接受; bèi dàjiā suǒ jiēshòu; accepted by everyone](bei4da4jia1suo3jie1shou4.wav) | Approved / welcomed | [新规定被大家所接受了。; Xīn guīdìng bèi dàjiā suǒ jiēshòu le.; The new rule was accepted by everyone.](xin1gui1ding4bei4da4jia1suo3jie1shou4le0.wav) |
| [为情所困; wéi qíng suǒ kùn; trapped / troubled by love](wei2qing2suo3kun4.wav) | Overcome by emotion | [他一直为情所困。; Tā yìzhí wéi qíng suǒ kùn.; He has always been troubled by romantic entanglements.](ta1yi4zhi2wei2qing2suo3kun4.wav) |
