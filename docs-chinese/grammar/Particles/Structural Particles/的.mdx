# 的 (de)

的 acts like grammatical glue, attaching descriptions, possessions, or clauses to a noun.

:::note
> **The Universal Pattern:**  
> **[Modifier / Description]** + [的; de; Modifying particle](de0.wav) + **[Noun / Head Word]**
:::

## 5. 是……的 (shì... de)

The 是……的 (shì... de) construction is used to emphasize specific details of an action that already happened in the past, rather than simply stating that an action occurred.

Since Mandarin Chinese does not have grammatical tenses, the 是……的 pattern relies on the presupposition that the main action is a completed past event. It then draws attention to how, when, where, with whom, or why that past action took place.

是 (shì) is optional in affirmative sentences: In spoken Chinese, 是 is frequently dropped, but 的 remains at the end (e.g., 我昨天来的 = I came yesterday).

:::note
Subject** + 是 + [Detail Emphasized] + Verb + 的
:::

| Emphasis Detail | Example Sentence |
| :--- | :---: |
| **Time** *(When)* | [我是昨天来的。; Wǒ shì zuótiān lái de.; I came yesterday.](wo3shi4zuo2tian1lai2de0.wav) |
| **Place** *(Where)* | [我们是在北京认识的。; Wǒmen shì zài Běijīng rènshi de.; We met in Beijing.](wo3men0shi4zai4bei3jing1ren4shi0de0.wav) |
| **Manner** *(How)* | [他是坐飞机去的。; Tā shì zuò fēijī qù de.; He went by airplane.](ta1shi4zuo4fei1ji1qu4de0.wav) |
| **Agent** *(Who)* | [这本书是他写的。; Zhè běn shū shì tā xiě de.; This book was written by him.](zhe4ben3shu1shi4ta1xie3de0.wav) |

## 6. Avoiding "的 Stacking"

Because **的** has so many functions, learners often create unnatural sentences by chaining several together:

> ❌ **Clunky:** [我的朋友的妈妈的猫; wǒ de péngyou de māma de māo; My friend's mom's cat (overloaded 的)](wo3de0peng2you0de0ma1ma0de0mao1.wav)  

> ✔️ **Natural:** [我朋友妈妈的猫; wǒ péngyou māma de māo; My friend's mom's cat](wo3peng2you0ma1ma0de0mao1.wav)

## 7. Polyphonic Warning

While **99%** of the time **的** is the neutral-tone grammatical particle *de*, it is a multi-tone character in a few specific vocabulary words:

* **dí** (2nd tone — *true, real*):
  * [的确; díquè; Indeed / Definitely](di2que4.wav)
* **dì** (4th tone — *target, bullseye*):
  * [目的; mùdì; Purpose / Goal](mu4di4.wav)
  * [标的; biāodì; Target / Underlying object](biao1di4.wav)
