Prepositions

Mandarin prepositions (coverbs) front a prepositional phrase before the main verb to establish the spatial, temporal, instrumental, or relational frame of an action. Unlike English prepositions, many coverbs retain verbal roots and strictly govern word order directly preceding the verb phrase.

Space, Direction & Distance (处所、方向与距离)​

朝; cháo; Towards / Facing​

  • Usage: 朝 + Direction / Location / Target + Verb (emphasizes physical orientation or movement heading towards a point).
  • Example: 这列高铁朝终点站疾驰而去。; Zhè liè gāotiě cháo zhōngdiǎnzhàn jíchí ér qù.; This high-speed train speeds towards the terminal station.

从; cóng; From / Starting from​

  • Usage: 从 + Spatial Starting Point + Verb / 往 / 到 (marks geographic or physical point of departure).
  • Example: 外交官从那座使馆步行到会议厅。; Wàijiāoguān cóng nà zuò shǐguǎn bùxíng dào huìyìtīng.; The diplomat walked from that embassy to the conference hall.

离; lí; Away from / Distant from​

  • Usage: Location A + 离 + Location B + Adverb + 远 / 近 / Metric Distance (measures static separation between two reference points).
  • Example: 这家新客栈离风景区只有两公里。; Zhè jiā xīn kèzhàn lí fēngjǐngqū zhǐ yǒu liǎng gōnglǐ.; This new inn is only two kilometers away from the scenic area.

往; wǎng; Toward / In direction of​

  • Usage: 往 + Direction / Target + Action Verb (directs motion along a specific trajectory; commonly pairs with directional monosyllabic verbs).
  • Example: 邮递员骑着一辆摩托车往东拐去。; Yóudìyuán qí zhe yī liàng mótuōchē wǎng dōng guǎi qù.; The courier rode a motorcycle and turned toward the east.

向; xiàng; Towards / To (a target)​

  • Usage: 向 + Person / Cardinal Direction / Abstract Target + Verb (focuses on intended recipient or purposeful directionality).
  • Example: 记者向那位著名的教授提出了三个疑问。; Jìzhě xiàng nà wèi zhùmíng de jiàoshòu tíchū le sān gè yíwèn.; The reporter posed three questions to that renowned professor.

沿; yán; Along / Following​

  • Usage: 沿 + Route / Perimeter / Waterway / Street + Movement Verb (specifies linear path adherence).
  • Example: 巡逻队沿那条蜿蜒的河流搜寻失踪人员。; Xúnluóduì yán nà tiáo wānyán de héliú sōuxún shīzōng rényuán.; The patrol team searched along that winding river for missing personnel.

在; zài; At / In / On​

  • Usage: 在 + Physical Location + Action Verb (establishes the locative scene where an action occurs).
  • Example: 建筑师在这间安静的画室里绘制图纸。; Jiànzhùshī zài zhè jiān ānjìng de huàshì lǐ huìzhì túzhǐ.; The architect draws blueprints in this quiet studio.

自; zì; From / Originating from​

  • Usage: 自 + Spatial Origin + Verb (formal/written register equivalent of 从).
  • Example: 这批珍贵的文物自欧洲海运抵达港口。; Zhè pī zhēnguì de wénwù zì Ōuzhōu hǎiyùn dǐdá gǎngkǒu.; This batch of precious cultural relics arrived at the port via sea freight from Europe.

Time & Opportunity (时间与时机)​

趁; chèn; Seizing / Taking advantage of​

  • Usage: 趁 + Temporal Window / Opportunity / Fleeting State + Action Verb (acts before conditions change).
  • Example: 工程师打算趁天气晴朗检修那架风力发电机。; Gōngchéngshī dǎsuàn chèn tiānqì qínglǎng jiǎnxiū nà jià fēnglì fādiànjī.; The engineer plans to seize the clear weather to inspect and repair that wind turbine.

从; cóng; From / Since​

  • Usage: 从 + Temporal Starting Point + 起 / 开始 / 到... (designates temporal origin).
  • Example: 这间实验室从下周一开始实行封闭管理。; Zhè jiān shíyànshì cóng xià zhōu yī kāishǐ shíxíng fēngbì guǎnlǐ.; This laboratory will implement closed-off management starting next Monday.

当; dāng; When / At the time of​

  • Usage: 当 + Event / Temporal Anchor + (的时 / 的时候)，Main Clause (synchronizes primary event with a specific moment).
  • Example: 当警报声响起时，值班医生迅速赶往急诊室。; Dāng jǐngbàoshēng xiǎngqǐ shí, zhíbān yīshēng xùnsù gǎnwǎng jízhěnshì.; When the alarm sounded, the on-duty doctor rushed swiftly to the emergency room.

随着; suízhe; Along with / In the wake of​

  • Usage: 随着 + Evolving Situation / Trend, Main Clause (governs concurrent gradual developments).
  • Example: 随着经济结构优化，这家企业逐步拓展了海外市场。; Suízhe jīngjì jiégòu yōuhuà, zhè jiā qǐyè zhúbù tuòzhǎn le hǎiwài shìchǎng.; Along with the optimization of the economic structure, this enterprise gradually expanded its overseas market.

在; zài; In / During (a time frame)​

  • Usage: 在 + Temporal Duration / Period + 期间 / 之中 / 内 (frames action within a bounded period).
  • Example: 代表团在整个访问期间签署了一项合作备忘录。; Dàibiǎotuán zài zhěnggè fǎngwèn qījiān qiānshǔ le yī xiàng hézuò bèiwànglù.; The delegation signed a memorandum of cooperation during the entire visit.

自; zì; Since / From (formal)​

  • Usage: 自 + Historical Point / Date + 以来 / 起 (formal temporal point of inception).
  • Example: 自去年改革以来，该部门的工作效率显著提高。; Zì qùnián gǎigé yǐlái, gāi bùmén de gōngzuò xiàolǜ xiǎnzhù tígāo.; Since last year's reform, this department's work efficiency has improved noticeably.

Target, Recipient & Accompaniment (对象、受益者与伴随)​

对; duì; To / Toward / Regarding​

  • Usage: 对 + Person / Entity / Issue + Verb / Attitudinal Adjective (marks recipient of attitudes, evaluations, or actions).
  • Example: 导师对这篇论文的论证逻辑感到满意。; Dǎoshī duì zhè piān lùnwén de lùnzhèng luóji gǎndào mǎnyì.; The advisor felt satisfied with the argumentative logic of this thesis.

给; gěi; To / For (beneficiary / recipient)​

  • Usage: 给 + Recipient + Verb or Verb + 给 + Recipient (marks transference recipient or service beneficiary).
  • Example: 前台秘书给那位应聘者递上一杯热茶。; Qiántái mìshū gěi nà wèi yìngpìnzhě dì shang yī bēi rèchá.; The front-desk receptionist handed a cup of hot tea to that applicant.

跟; gēn; With / And / From​

  • Usage: 跟 + Interactive Partner + Verb (interactive accompaniment or comparative baseline).
  • Example: 会计师跟那家银行的业务经理核对了账户账目。; Kuàijìshī gēn nà jiā yínháng de yèwù jīnglǐ héduì le zhànghù zhàngmù.; The accountant verified the account entries with that bank's operations manager.

和; hé; With / Together with​

  • Usage: 和 + Companion + 一起 + Verb (joint participation in an action).
  • Example: 地质学家和考察队员一起攀登了那座险峻的山峰。; Dìzhìxuéjiā hé kǎochá duìyuán yīqǐ pāndēng le nà zuò xiǎnjùn de shānfēng.; The geologist climbed that precipitous mountain peak together with the expedition team members.

同; tóng; With / And (formal)​

  • Usage: 同 + Diplomatic / Formal Partner + Verb (mid-to-high register coverb for bilateral interactions).
  • Example: 外交部长同外宾就两国经贸合作举行了会谈。; Wàijiāo bùzhǎng tóng wàibīn jiù liǎng guó jīngmào hézuò jǔxíng le huìtán.; The foreign minister held talks with the foreign guests on bilateral economic and trade cooperation.

与; yǔ; With / And (formal / high-register)​

  • Usage: 与 + Counterpart + Verb (Formal / Written) (establishes high-register relational binding).
  • Example: 投资方与研发团队签订了一份具有约束力的合同。; Tóuzīfāng yǔ yánfā tuánduì qiāndìng le yī fèn jùyǒu yuēshùlì de hétong.; The investor signed a binding contract with the research and development team.

为; wèi; For / On behalf of​

  • Usage: 为 + Beneficiary / Client + Verb (indicates intentional service or action done for someone's sake).
  • Example: 社区志愿者为独居老人提供了一项免费理发服务。; Shèqū zhìyuànzhě wèi dújū lǎorén tígōng le yī xiàng miǎnfèi lǐfà fúwù.; Community volunteers provided a free haircut service for solitary seniors.

针对; zhēnduì; Aimed at / Directed against​

  • Usage: 针对 + Specific Issue / Target Problem + Action Verb (focuses an intervention or countermeasure).
  • Example: 专家组针对城市内涝制定了一套排水改造方案。; Zhuānjiāzǔ zhēnduì chéngshì nèilào zhìdìng le yī tào páishuǐ gǎizào fāng'àn.; The expert panel formulated a drainage renovation plan targeted at urban waterlogging.

Basis, Standard, Means & Route (依据、标准、方式与途径)​

按; àn; According to / By​

  • Usage: 按 + Metric / Sequence / Rate + Verb (governs numerical quotas, chronological order, or fixed rates).
  • Example: 这家诊所按就诊顺序发放预约号牌。; Zhè jiā zhěnsuǒ àn jiùzhěn shùnxù fāfàng yùyuē hàopái.; This clinic issues appointment number plates in accordance with the consultation sequence.

按照; ànzhào; In accordance with / Following​

  • Usage: 按照 + Codified Rules / Blueprints / Mandates + Verb (adherence to established criteria or procedural regulations).
  • Example: 质检员按照操作规程仔细检查了那批机械零件。; Zhìjiǎnyuán ànzhào cāozuò guīchéng zǐxì jiǎnchá le nà pī jīxiè língjiàn.; The quality inspector carefully inspected that batch of mechanical components according to operating procedures.

根据; gēnjù; According to / On the basis of​

  • Usage: 根据 + Empirical Evidence / Source Data / Facts, Predicate (cites empirical authority or premise for a conclusion).
  • Example: 气象台根据最新卫星云图发布了暴雨预警信号。; Qìxiàngtái gēnjù zuìxīn wèixīng yúntú fābù le bàoyǔ yùjǐng xìnhào.; The meteorological observatory issued a rainstorm warning signal based on the latest satellite cloud images.

基于; jīyú; Based on / In light of​

  • Usage: 基于 + Theoretical Premise / Data Foundation (Formal), Main Clause (formal cognitive or analytic foundation).
  • Example: 研究团队基于海量实验数据推导出一项新定理。; Yánjiū tuánduì jīyú hǎiliàng shíyàn shùjù tuīdǎo chū yī xiàng xīn dìnglǐ.; Based on massive experimental data, the research team derived a new theorem.

经; jīng; Through / Via / After​

  • Usage: 经 + Formal Process / Audit / Deliberation + Outcome (denotes passage through a mandatory procedural phase).
  • Example: 经董事会慎重表决，这项收购决议正式生效。; Jīng dǒngshìhuì shènzhòng biǎojué, zhè xiàng shōugòu juéyì zhèngshì shēngxiào.; After prudent voting by the board of directors, this acquisition resolution took effect officially.

据; jù; According to / Reportedly​

  • Usage: 据 + Authoritative Source + Reporting Verb / Clause (shortened form of 根据, strictly framing external testimony/reports).
  • Example: 据民航局通报，那架延误的国际航班已安全降落。; Jù mínhángjú tōngbào, nà jià yánwù de guójì hángbān yǐ ānquán jiàngluò.; According to the civil aviation bulletin, that delayed international flight has landed safely.

凭; píng; By virtue of / Relying on​

  • Usage: 凭 + Credentials / Evidence / Intuition + Action Verb (leverages proof, qualification, or inherent skill).
  • Example: 读者凭借书证可以在这栋图书馆借阅三册典籍。; Dúzhě píng jièshūzhèng kěyǐ zài zhè dòng túshūguǎn jièyuè sān cè diǎnjí.; Readers can borrow three volumes of classic books in this library by virtue of a library card.

通过; tōngguò; By means of / Through​

  • Usage: 通过 + Intermediary / Method / Medium + Goal Achieved (denotes instrument, conduit, or logistical medium).
  • Example: 求职者通过网络招聘渠道投递了一份精心准备的简历。; Qiúzhízhě tōngguò wǎngluò zhàopìn qúdào tóudì le yī fèn jīngxīn zhǔnbèi de jiǎnlì.; The job applicant submitted a meticulously prepared resume through online recruitment channels.

以; yǐ; By means of / Using / On the basis of​

  • Usage: 以 + Manner / Attitude / Means + Verb (formal coverb governing instrumental or stylistic modality).
  • Example: 辩手以饱满的热情和清晰的语速陈述了自己的观点。; Biànshǒu yǐ bǎomǎn de rèqíng hé qīngxī de yǔsù chénshù le zìjǐ de guāndiǎn.; The debater stated their viewpoint with abundant enthusiasm and a clear speaking pace.

Reason, Purpose & Role (原因、目的与身份)​

鉴于; jiànyú; In view of / Considering that​

  • Usage: 鉴于 + Objective Circumstance / Risk Factor, Resulting Policy / Action (introduces cautionary premise or administrative justification).
  • Example: 鉴于恶劣的暴风雪天气，铁路局取消了那班临客。; Jiànyú èliè de bàofēngxuě tiānqì, tiělùjú qǔxiāo le nà bān línkè.; In view of the severe blizzard weather, the railway bureau canceled that extra passenger train.

为; wèi; Because of / For​

  • Usage: 为 + Causal Stimulus / Target + (而) + Verb (expresses motivation, cause, or reaction trigger).
  • Example: 全体观众为那位运动员坚韧不拔的毅力热烈鼓掌。; Quántǐ guānzhòng wèi nà wèi yùndòngyuán jiānrèn-bùbá de yìlì rèliè gǔzhǎng.; The entire audience applauded enthusiastically on account of that athlete's tenacious perseverance.

为了; wèile; In order to / For the purpose of​

  • Usage: 为了 + Intended Goal / Future State, Action Clause (expresses intentional forward-looking purpose).
  • Example: 为了缓解早高峰交通拥堵，交警开通了一条潮汐车道。; Wèile huǎnjiě zǎogāofēng jiāotōng yōngdǔ, jiāojǐng kāitōng le yī tiáo cháoxī chēdào.; In order to alleviate morning peak traffic congestion, the traffic police opened a reversible lane.

由于; yóuyú; Due to / Because of​

  • Usage: 由于 + Objective Root Cause, Consequence (states explicit factual cause preceding a result).
  • Example: 由于突发地质灾害，矿区暂停了那处作业面的开采。; Yóuyú tūfā dìzhì zāihài, kuàngqū zàntíng le nà chù zuòyèmiàn de kāicǎi.; Due to a sudden geological disaster, the mining area suspended extraction at that working face.

作为; zuòwéi; As / In the capacity of​

  • Usage: 作为 + Role / Professional Title / Designated Status, Action (frames behavior via specific legal or functional identity).
  • Example: 作为这支研发团队的技术顾问，工程师承担了核心审查职责。; Zuòwéi zhè zhī yánfā tuánduì de jìshù gùwèn, gōngchéngshī chéngdān le héxīn shěnchá zhízé.; As the technical advisor of this R&D team, the engineer assumed the core review responsibilities.

Topic, Scope & Exclusion (关涉、范围与排除)​

除了; chúle; Except / Besides / Apart from​

  • Usage: 除了 + Excluded Item + (以外)，Subject + 都 / 也 / 还 + Verb (delineates exclusion or additive inclusion).
  • Example: 除了两件随身行李以外，旅客不能携带易燃易爆物品登机。; Chúle liǎng jiàn suíshēn xíngli yǐwài, lǚkè bù néng xiédài yìrán-yìbào wùpǐn dēngjī.; Except for two pieces of carry-on luggage, passengers may not carry inflammable or explosive items aboard the plane.

对于; duìyú; With regard to / As for​

  • Usage: 对于 + Macro Topic / Policy / Proposed Entity, Viewpoint Clause (isolates an issue as the topical focus of discourse).
  • Example: 对于城市绿化改造方案，市民代表纷纷发表了积极意见。; Duìyú chéngshì lǜhuà gǎizào fāng'àn, shìmín dàibiǎo fēnfēn fābiǎo le jījí yìjiàn.; Regarding the urban greening renovation plan, citizen representatives expressed positive opinions one after another.

关于; guānyú; Concerning / About​

  • Usage: 关于 + Subject Matter + Predicate or 关于 + Subject Matter + 的 + Noun (introduces thematic scope or modifies nominal titles).
  • Example: 学者发表了一篇关于新能源汽车电池回收的学术论文。; Xuézhě fābiǎo le yī piān guānyú xīn-néngyuán qìchē diànchí huíshōu de xuéshù lùnwén.; The scholar published an academic paper concerning the recycling of new energy vehicle batteries.

就; jiù; Concerning / With respect to​

  • Usage: 就 + Specific Disputed Item / Agenda + Verb (e.g., 讨论, 交换意见) (narrows discourse strictly to a single targeted point).
  • Example: 双方谈判代表就那项贸易关税纠纷坦诚交换了意见。; Shuāngfāng tánpàn dàibiǎo jiù nà xiàng màoyì guānshuì jiūfēn tǎncéng jiāohuàn le yìjiàn.; Negotiating representatives from both sides candidly exchanged views regarding that trade tariff dispute.

连; lián; Even (including)​

  • Usage: 连 + Extreme / Baseline Exemplar + 都 / 也 + Predicate (introduces an extreme case to emphasize emphatic scope).
  • Example: 连经验最丰富的资深技师也没能修好那台精密仪器。; Lián jīngyàn zuì fēngfù de zīshēn jìshī yě méi néng xiū hǎo nà tái jīngmì yíqì.; Even the most experienced senior technician could not repair that precision instrument.

至于; zhìyú; As for / Regarding​

  • Usage: Clause 1; 至于 + Divergent Secondary Topic, Clause 2 (marks an explicit thematic shift to a separate matter).
  • Example: 这笔货款我们已经付清，至于产品运输保险则需要由供货商承担。; Zhè bǐ huòkuǎn wǒmen yǐjīng fùqīng, zhìyú chǎnpǐn yùnshū bǎoxiǎn zé xūyào yóu gōnghuòshāng chéngdān.; We have already cleared this payment for goods; as for product transit insurance, it needs to be borne by the supplier.

Classical & High-Register Polysemous Coverb (文雅多义介词)​

于; yú; In / At / To / From / Than​

  • Usage: Verb / Adjective + 于 + Entity / Benchmark (classical marker for location, time, target, or comparative degree).
  • Example: 这种新型复合材料在耐热性能上明显优于传统钢铁。; Zhè zhǒng xīnxíng fùhé cáiliào zài nàirè xìngnéng shang míngxiǎn yōuyú chuántǒng gāngtiě.; This new composite material is distinctly superior to traditional steel in heat-resistant performance.

Disposal, Passive & Comparative Markers (处置、被动与比较标记)​

把; bǎ; Disposal marker (direct object focus)​

  • Usage: Subject + 把 + Definite Object + Action Verb + Resultative / Directional Complement (fronts object to express active disposal and state change).
  • Example: 主厨把那条鲜活的草鱼切成了薄片。; Zhǔchú bǎ nà tiáo xiānhuó de cǎoyú qiē chéng le báopiàn.; The head chef sliced that live grass carp into thin pieces.

被; bèi; Passive voice marker​

  • Usage: Patient + 被 + (Agent) + Verb + Complement / Result (shifts semantic patient to subject position, marking passive endurance).
  • Example: 那份绝密档案被机要员妥善存放在了保险箱内。; Nà fèn juémì dāng'àn bèi jīyàoyuán tuǒshàn cúnfàng zài le bǎoxiǎnxiāng nèi.; That top-secret archive was properly stored in the safe by the confidential clerk.

比; bǐ; Compared to / Than​

  • Usage: Entity A + 比 + Entity B + Adjective + Degree / Numerical Difference (sets structural benchmark for comparative degree).
  • Example: 这套智能灌溉系统比旧设备节省了三成电量。; Zhè tào zhìnéng guàngài xìtǒng bǐ jiù shèbèi jiéshěng le sān chéng diànliàng.; This intelligent irrigation system saves thirty percent more power than the old equipment.

叫; jiào; Passive agent marker (colloquial)​

  • Usage: Patient + 叫 + Specific Agent + Action Verb + Result (spoken passive marker; the agent cannot be omitted).
  • Example: 信封里的聘书叫顽皮的宠物狗撕成了碎片。; Xìnfēng lǐ de pìnshū jiào wánpí de chǒngwùgǒu sī chéng le suìpiàn.; The letter of appointment inside the envelope was torn to shreds by the naughty pet dog.

让; ràng; Passive agent marker (colloquial)​

  • Usage: Patient + 让 + Specific Agent + Action Verb + Result (spoken passive marker denoting an adverse or unexpected result; agent mandatory).
  • Example: 晒在院子里的被褥让一场突如其来的阵雨淋湿了。; Shài zài yuànzi lǐ de bèirù ràng yī cháng tūrúqílái de zhènyǔ línshī le.; The bedding drying in the courtyard was soaked by a sudden downpour.

由; yóu; Handled by / Due to (agent of responsibility)​

  • Usage: Task / Duty / Obligation + 由 + Designated Agent + Verb (assigns exclusive institutional or personal agency).
  • Example: 这项复杂的文物修复工程由几位经验丰富的老匠人主持。; Zhè xiàng fùzá de wénwù xiūfù gōngchéng yóu jǐ wèi jīngyàn fēngfù de lǎo jiàngrén zhǔchí.; This complex cultural relics restoration project is presided over by several experienced veteran artisans.
