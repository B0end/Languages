El Nominativo es la **forma base o de diccionario**. No sufre modificaciones por verbos ni por preposiciones:

```text
                           ┌── Sustantivos Singulares (Género base)
                           ├── Sustantivos Plurales (-ы, -и, -а, -я)
                           ├── Modificadores: Demostrativos y Adjetivos
CASO NOMINATIVO ───────────┼── Pronombres Sujeto (Я, Ты, Он...)
(Quién / Qué ejecuta)      ├── Cópula Cero en Presente (Sujeto = Predicado)
                           └── Posesión con "У меня есть..." (Lo que tienes es el sujeto)
```

Responde siempre a dos preguntas fundamentales:
* [Кто?;; ¿Quién? / Who?](Kto.wav) — Para personas y seres vivos (*animado*).
* [Что?;; ¿Qué? / What?](Chto.wav) — Para objetos, lugares y conceptos (*inanimado*).

## ¿Cómo saber si una palabra va en Nominativo?

1. **¿Es quien realiza el verbo?** ➔ **Nominativo** ([Студент учится;; El estudiante estudia / The student studies](StudentUchitsya.wav)).
2. **¿Es una oración A = B en presente?** ➔ **Nominativo** ([Он врач;; Él es médico / He is a doctor](OnVrach.wav)).
3. **¿Es lo que se posee con *У [alguien] есть...*?** ➔ **Nominativo** ([У меня есть машина;; Tengo un carro / I have a car](UMenyaEstMashina.wav)).
4. **¿Es el título de un libro o un cartel en la calle?** ➔ **Nominativo** ([Аптека;; Farmacia / Pharmacy](Apteka.wav)).
