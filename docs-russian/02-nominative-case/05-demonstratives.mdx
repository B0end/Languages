# Demonstratives

Demonstratives are words used to point to specific people, objects, or ideas. 

In English, you have a two-way distinction: **this/these** (near) and **that/those** (far). 
In Spanish, you traditionally have a three-way distinction: **este** (near), **ese** (middle), and **aquel** (far).

Russian works conceptually like English (a two-way system: *near* and *far*), but grammatically it behaves like Spanish (it must agree with the noun in **gender** and **number**). On top of that, Russian adds **cases** (declensions).

---

## The Proximal Demonstrative: "This / These" (*Este / Estos*)

The base root in Russian is **Эт-**.

Just like in Spanish (*este, esta, estos, estas*), Russian changes depending on whether the noun is masculine, feminine, neuter, or plural.

Here are the forms in the **Nominative case** (the dictionary form used for subjects):

| Gender / Number | Russian | Spanish equivalent | English equivalent |
| :--- | :--- | :--- | :--- |
| **Masculine** | [Этот;; Este / This](Этот.wav) | este | this |
| **Feminine** | [Эта;; Esta / This](Эта.wav) | esta | this |
| **Neuter** | [Это;; Esto / This](Это.wav) | esto (as an adjective) | this |
| **Plural** (all genders) | [Эти;; Estos, estas / These](Эти.wav) | estos / estas | these |

#### Examples:
* Masculine:
  [Этот дом очень старый;; Este edificio es muy viejo / This house is very old](Этотдомоченьстарый.wav)
* Feminine:
  [Эта книга интересная;; Este libro es interesante / This book is interesting](Этакнигаинтересная.wav)
  *(Notice: Russian [книга;; libro / book](Книга.wav) is feminine, while Spanish **libro** is masculine! Always match the Russian gender).*
* Neuter:
  [Это окно открыто;; Esta ventana está abierta / This window is open](Этоокнооткрыто.wav)
* Plural:
  [Эти студенты учат русский язык;; Estos estudiantes estudian ruso / These students study Russian](Этистудентыучатрусскийязык.wav)

## Crucial Distinction: "This thing" vs. "This is..."

1. **Adjective ("This [noun]"):** It changes according to the noun.
   * [Этот кофе горячий;; Este café está caliente / This coffee is hot](Этоткофегорячий.wav)

2. **Neutral Pronoun / Statement ("This is... / Esto es..."):** Always use the invariant neuter word **Это**, no matter the gender or number of what follows! Think of it as the Spanish generic **"Esto es..."** or English **"This is..."**.
   * [Это мой брат;; Este es mi hermano / This is my brother](Этомойбрат.wav)
   * [Это моя машина;; Este es mi coche / This is my car](Этомоямашина.wav)
   * [Это мои друзья;; Estos son mis amigos / These are my friends](Этомоидрузья.wav)

## The Distal Demonstrative: "That / Those" (*Ese / Aquel*)

To refer to something farther away (English **that/those**, Spanish **ese/aquel**), Russian uses the root **Т-**.

| Gender / Number | Russian | Spanish equivalent | English equivalent |
| :--- | :--- | :--- | :--- |
| **Masculine** | [Тот;; Ese, aquel / That](Тот.wav) | ese / aquel | that |
| **Feminine** | [Та;; Esa, aquella / That](Та.wav) | esa / aquella | that |
| **Neuter** | [То;; Eso, aquello / That](То.wav) | eso / aquello | that |
| **Plural** (all genders) | [Те;; Esos, aquellos / Those](Те.wav) | esos / aquellos | those |

#### Examples:
* [Тот парень говорит по-испански;; Aquel chico habla español / That guy speaks Spanish](Тотпареньговоритпоиспански.wav)
* [Та девушка — моя сестра;; Aquella chica es mi hermana / That girl is my sister](Тадевушкамоясестра.wav)
* [То здание далеко;; Aquel edificio está lejos / That building is far away](Тозданиедалеко.wav)
* [Те люди ждут автобус;; Aquellas personas esperan el autobús / Those people are waiting for the bus](Телюдиждутавтобус.wav)

## The Qualitative Demonstrative: "Такой" (*Tal / Tan / Such*)

Russian has another demonstrative adjective: [Такой;; Tal, tan / Such, so](Такой.wav) (fem: [такая;; tal, tan / such, so](Такая.wav), neut: [такое;; tal, tan / such, so](Такое.wav), plural: [такие;; tales, tan / such, so](Такие.wav)). 

It translates directly to Spanish **tan / tal / semejante** or English **such a / so / like this**:

* [Такой красивый день!;; ¡Un día tan hermoso! / Such a beautiful day!](Такойкрасивыйдень.wav)
* [Я не люблю такие фильмы;; No me gustan tales películas / I don't like such movies](Янелюблютакиефильмы.wav)
* [Почему ты такой грустный?;; ¿Por qué estás tan triste? / Why are you so sad?](Почемутытакойгрустный.wav)
