# Reflexive Verbs (-ся / -сь)

In Spanish, reflexive actions use separate pronouns placed before or after the verb (*me lavo, lavarse, te llamas*). In English, you use reflexive pronouns like *myself, yourself, itself*.

In Russian, reflexivity is simpler: it is marked by a **postfix** permanently glued to the very tail of the verb: **-ся** or **-сь**.

```
  Обычный глагол (Regular):     Мыть      (To wash someone / something)
                                 │
                            + -ся / -сь
                                 ▼
  Возвратный глагол (Reflexive): Мыться   (To wash oneself / Lavarse)
```

Historically, **-ся** is an ancient contraction of the pronoun **себя** (*oneself / a sí mismo*).

---

## 1. The Rule: When to Use -ся vs. -сь

The choice between **-ся** and **-сь** depends strictly on what comes immediately before it:

```
┌────────────────────────────────────────────────────────────────────────┐
│  • After a CONSONANT (or soft sign "ь"):  Use -СЯ                      │
│  • After a VOWEL:                         Use -СЬ                      │
└────────────────────────────────────────────────────────────────────────┘
```

* **Why?** Euphony (ease of pronunciation). Russian avoids double vowels (*-а-ся* flows better as *-а-сь*) and avoids clashing consonants.

## 3. Past Tense with -ся / -сь

In the past tense, Russian verbs end in gender markers: **-л** (masculine), **-ла** (feminine), **-ло** (neuter), **-ли** (plural). The exact same vowel/consonant rule applies:

| Gender | Base Past | Ends in... | Add | Example: [Одеваться;; Vestirse](Одеваться.wav) |
| :--- | :--- | :--- | :---: | :--- |
| **Masculine** | одева-**л** | Consonant | **-ся** | [Он одевался;; Él se vestía / He got dressed](ОнОдевался.wav) |
| **Feminine** | одева-л-**а** | Vowel | **-сь** | [Она одевалась;; Ella se vestía / She got dressed](ОнаОдевалась.wav) |
| **Neuter** | одева-л-**о** | Vowel | **-сь** | Оно одевалось *(It got dressed)* |
| **Plural** | одева-л-**и** | Vowel | **-сь** | [Они одевались;; Ellos se vestían / They got dressed](ОниОдевались.wav) |

## 4. The Famous Russian Trap: -тся vs. -ться

Both **-тся** (3rd person present) and **-ться** (infinitive) sound **identical** in spoken Russian: they are both pronounced like a hard **[ца]** (*tsa*).

Even native Russian speakers constantly misspell this! Here is how to never make the mistake:

```
┌────────────────────────────────────────────────────────────────────────┐
│  Ask the verb a question:                                              │
│                                                                        │
│  1. Does the question have a soft sign (Ь)?                            │
│     ➔ Что делатЬ? (What to do?) ➔ Write -ТЬСЯ (Infinitive)             │
│                                                                        │
│  2. Does the question have NO soft sign?                               │
│     ➔ Что делает? (What does he/she do?) ➔ Write -ТСЯ (3rd Person)     │
└────────────────────────────────────────────────────────────────────────┘
```

* *Он хочет (что делать?) [учиться;; estudiar / to study](Учиться.wav)* ➔ **-ться** (Infinitive)
* *Он сейчас (что делает?) [учится;; estudia / studies](ОнУчится.wav)* ➔ **-тся** (Present 3rd person)

## 5. The 5 Meanings of -ся

Russian uses the reflexive postfix for far more than just actions done to oneself:

### 1. True Reflexive (Self-Directed Action)
The subject and the object are the exact same entity:
* [Мыть;; Lavar / To wash](Мыть.wav) *(something else)* ➔ [Мыться;; Lavarse / To wash oneself](Мыться.wav)
* [Одевать;; Vestir / To dress](Одевать.wav) *(someone else)* ➔ [Одеваться;; Vestirse / To get dressed](Одеваться.wav)
* [Брить;; Afeitar / To shave](Брить.wav) ➔ [Бриться;; Afeitarse / To shave oneself](Бриться.wav)

---

### 2. Reciprocal Actions (Each Other / Mutually)
Indicates two or more people doing an action to one another:
* [Целовать;; Besar / To kiss](Целовать.wav) ➔ [Целоваться;; Besarse / To kiss each other](Целоваться.wav)
* [Встречать;; Encontrar / To meet](Встречать.wav) ➔ [Встречаться;; Encontrarse / To meet up, date](Встречаться.wav)
* [Обнимать;; Abrazar / To hug](Обнимать.wav) ➔ [Обниматься;; Abrazarse / To hug each other](Обниматься.wav)

---

### 3. Inherent State, Emotion, or Change
Verbs describing internal feelings, psychological reactions, or physical position:
* [Радоваться;; Alegrarse / To rejoice, be glad](Радоваться.wav)
* [Смеяться;; Reírse / To laugh](Смеяться.wav)
* [Сердиться;; Enfadarse / To be angry](Сердиться.wav)
* [Садиться;; Sentarse / To sit down](Садиться.wav)

---

### 4. Passive / Inanimate Actions
Inanimate objects cannot perform actions on their own; `-ся` functions like the passive voice or the Spanish *se pasivo*:
* *Магазин [открывается;; se abre / opens](Открывается.wav) в 9:00* (The shop opens at 9:00).
* *Дверь [закрывается;; se cierra / closes](Закрывается.wav)* (The door is closing).
* *Как это [называется;; se llama / is called](Называется.wav)?* (What is this called?).

---

### 5. "Locked" Reflexives (Verbs that ONLY exist with -ся)
Some verbs in Russian have lost their non-reflexive base entirely. You cannot remove `-ся` from them:

| Verb | Meaning (ES / EN) | Note |
| :--- | :--- | :--- |
| [Бояться](Бояться.wav) | Tener miedo / To fear, be afraid | *There is no such verb as "боять"* |
| [Улыбаться](Улыбаться.wav) | Sonreír / To smile | *No "улыбать"* |
| [Надеяться](Надеяться.wav) | Esperar, tener esperanza / To hope | *No "надеять"* |
| [Гордиться](Гордиться.wav) | Enorgullecerse / To be proud | *No "гордить"* |
| [Нравиться](Нравиться.wav) | Gustar / To please, be liked | Used with the Dative case |

---

## 6. Summary Checklist

When working with reflexive verbs:

1. Conjugate the verb root normally using **Group 1** or **Group 2** rules.
2. Look at the last letter of that conjugated form:
   * Consonant or soft sign? ➔ Tack on **-ся**.
   * Vowel? ➔ Tack on **-сь**.
3. Remember that **-ться** and **-тся** sound identical: check whether you need an infinitive (*что делать?*) or a conjugated form (*что делает?*).
